Project Title

Login Anomaly Detection System Using Python & Statistics

⸻

Overview

This project analyzes login attempt data and detects abnormal activity using statistical methods such as mean and z-score analysis.

⸻

Features

* Calculates average login attempts
* Computes standard deviation
* Applies z-score anomaly detection
* Flags suspicious login activity

⸻

Example Output

* Value: 20
* Z-score:3.0
* Anomaly detected: 20
